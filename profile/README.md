# Sebastian Software

We are a German software company building dependable products and open-source developer tools across TypeScript, Rust, and AI. We like difficult technical problems, explicit trade-offs, and software whose claims can be checked in its code, tests, benchmarks, and documentation.

Open source shaped our careers. Today, we maintain the tools we wish existed: focused libraries, native engines, and practical infrastructure for developers and AI agents.

## What we are building

- **[Dalo](https://github.com/sebastian-software/dalo)** — one source of truth for the skills your AI agents run, with versioned sources, approvals, conflict handling, drift detection, and deterministic synchronization.
- **[Palamedes](https://github.com/sebastian-software/palamedes)** — open-source internationalization tooling for TypeScript applications, with a Rust-native toolchain and first-party framework integrations.
- **[Ferrocat](https://github.com/sebastian-software/ferrocat)** — a Rust-native translation catalog engine for parsing, updating, auditing, reviewing, and compiling localized product copy.
- **[Ferromark](https://github.com/sebastian-software/ferromark)** — secure Markdown-to-HTML for Rust and Node.js, with full GitHub Flavored Markdown support and reproducible benchmarks.
- **[Ferroni](https://github.com/sebastian-software/ferroni)** — a pure-Rust Oniguruma-compatible regular-expression engine and multi-pattern scanner, built without a C toolchain.
- **[Sebastian Software Skills](https://skills.sebastian-software.com)** — open-source skills that turn repeated professional practice into explicit workflows for capable AI agents.
